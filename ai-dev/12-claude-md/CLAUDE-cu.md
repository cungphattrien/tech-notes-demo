# Sổ chi tiêu

Viết code sạch và theo best practice. Cẩn thận khi sửa. Tuân theo quy ước của dự án.

## Lệnh
- Chạy test: `npm run test:watch`
- Chạy bot: `npm run bot`
- Xem `docs/kien-truc.md` để hiểu cấu trúc.

## Ghi chú
- Test nằm ở `src/so-chi-tieu.test.ts`.
- Logic chính nằm ở `src/phan-loai.ts`.
- Kiểm tra kiểu bằng `npm run kiem-kieu`.
