# Đơn hàng Mộc — trạng thái ban đầu

Hệ thống đơn hàng của quán cà phê Mộc lúc bạn mới nhận. Trang danh sách đơn đang **bị sập**.

```bash
node src/server.ts
# mở http://localhost:3000/don-hang  → "Lỗi máy chủ", stack trace in ở terminal
```

Đọc tiếp: tập 1 "Đọc stack trace" (thư mục `../01-doc-stack-trace`).
