# Tập 5 — Chuẩn bị phỏng vấn junior developer trong một tuần

Mọi chi tiết về Minh và công ty A là minh họa.

- `ke-hoach-7-ngay.md` — lịch 7 ngày, mỗi ngày khoảng 2 giờ.
- `danh-sach-on-tap.md` — yêu cầu của tin A chia ba nhóm: dự án, 15 câu kiến thức nền, code trực tiếp.
- `cau-chuyen-du-an.md` — giới thiệu dự án trong 2 phút.
- `cau-hoi-hoi-lai.md` — câu hỏi để hỏi lại nhà tuyển dụng.
- `bai-luyen/` — bài luyện code 20 phút: bản đầu (sai khi qua năm) và bản sửa có test.

```bash
node bai-luyen/ban-dau.ts                 # bản đầu: tháng 12 của hai năm bị cộng chung
node bai-luyen/tong-theo-thang.test.ts    # bản sửa: 3 test
```

Cần Node.js 22.18+.

Còn lại: buổi phỏng vấn có phần code trực tiếp trước mặt người phỏng vấn. Tập 6.
