# Danh sách ôn tập, lấy từ yêu cầu của tin A (minh họa)

Yêu cầu bắt buộc: React, TypeScript, Git; hiểu REST API. Ưu tiên: Next.js; đã viết unit test.

## Nhóm 1 — Kể về dự án của mình (Thứ Sáu)
- Giới thiệu app ghi chi tiêu trong 2 phút.
- Vì sao chọn Next.js, vì sao lưu dữ liệu ở đâu.
- Một lỗi khó đã sửa và cách tìm ra nó.
- 21 unit test kiểm tra những gì, có gì chưa test.

## Nhóm 2 — Kiến thức nền (Thứ Bảy, Thứ Hai), 15 câu
JavaScript / TypeScript
1. `let`, `const`, `var` khác nhau thế nào?
2. `==` và `===`.
3. Promise và `async/await`: đoạn code chạy theo thứ tự nào?
4. `map`, `filter`, `reduce`: viết lại một vòng `for` bằng chúng.
5. Closure là gì, ví dụ trong code của mình.
6. `type` và `interface` trong TypeScript.
7. `unknown` khác `any` thế nào.
8. Đọc một stack trace: tìm dòng đầu tiên thuộc code của mình.
React / Next.js
9. Vì sao không sửa trực tiếp state.
10. `useEffect` chạy khi nào, mảng phụ thuộc để làm gì.
11. `key` trong danh sách để làm gì.
12. Server Component và Client Component trong Next.js.
Git / REST / test
13. Một pull request tốt cần gì.
14. GET, POST, PUT, DELETE và mã 200, 400, 401, 404, 500.
15. Unit test là gì, làm sao biết một test có tác dụng.

## Nhóm 3 — Code trực tiếp (Chủ Nhật)

- Một bài tự chọn cùng cỡ: lọc, nhóm, sắp xếp một danh sách.
