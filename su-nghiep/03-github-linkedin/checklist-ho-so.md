# Checklist 15 phút cho GitHub và LinkedIn

## GitHub
- [ ] Ảnh đại diện và tên thật (hoặc tên giống trong CV).
- [ ] README trang cá nhân: bạn làm gì, đang tìm vị trí gì, một dự án nên xem trước, cách liên hệ.
- [ ] Ghim tối đa 6 repo: dự án chính trước, không ghim repo rỗng, bài tập trên lớp hay repo fork chưa sửa gì.
- [ ] Mỗi repo được ghim có mô tả một dòng, link bản chạy thử ở mục "Website", và README.
- [ ] Mở bằng điện thoại: bản chạy thử có mở được không?

## LinkedIn
- [ ] Tiêu đề nói bạn làm gì và bằng công nghệ gì, không chỉ "đang tìm việc".
- [ ] Mục Giới thiệu: vài dòng đầu đủ để người đọc hiểu bạn là ai mà không cần bấm "xem thêm".
- [ ] Mục Đáng chú ý có link bản chạy thử và repo.
- [ ] Tên, tên trường, thời gian học, dự án khớp với CV.
- [ ] Link LinkedIn trong CV và link CV/GitHub trên LinkedIn đều bấm được.
